# DriverScoreChain

DriverScoreChain is a blockchain-based driver behavior assessment and monetization system developed using Hyperledger Fabric.

The system evaluates driver behavior through three telematics-based metrics:

- Anomalous acceleration/deceleration;
- Abrupt direction changes;
- Continuous driving time (fatigue indicator).

Based on these metrics, a risk score is calculated and used to apply rewards or penalties. The results are securely stored on a Hyperledger Fabric blockchain to ensure transparency, integrity, and traceability.
