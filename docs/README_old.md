Nessa pasta contém o seguinte:
- enrollAdmin.js: codigo para registrar um admin na rede (usuário com permissão de registrar)
- register.js: codigo de registro que usa o formato padrão (Chave e certificado variado do certificado original do fabric)
- invoke.js: codigo cliente de invocação de chaincode usando a nova api do fabric. Baseado no chaincode braketester, mas a personalização é simples.
