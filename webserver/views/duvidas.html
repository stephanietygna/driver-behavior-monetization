Dúvidas Frequentes

Como gerar uma chave privada EC usando OpenSSL?

Você pode gerar uma chave privada EC com o comando:
openssl genpkey -algorithm EC -pkeyopt ec_paramgen_curve:prime256v1 -out chave_privada.pem
Isso criará um arquivo chamado chave_privada.pem contendo sua chave privada. Essa chave é do padrão prime256v1 e em formato PKCS#8, que é o formato esperado pelo sistema.

Qual é o formato aceito para o upload de arquivos no sistema?

Atualmente, o sistema aceita arquivos nos formatos JSON e CSV. Outros formatos não são suportados.

Minha chave está segura ao usar no servidor?

A chave privada é processada de forma segura no servidor. Ela não é armazenada em nenhum lugar e é usada apenas para assinar transações temporariamente, não necessitando armazenar a chave em local algum ou transferir para o servidor.

Como faço para assinar um digest com minha chave privada?

Você deve carregar a chave privada no formulário, escolher o chaincode a ser executado, inserir os dados para processamento e pressionar o botão "Executar chaincode".
